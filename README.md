# المشروع الكامل — نسخة Netlify

هذه حزمة المشروع الحالي بالعربية والإنجليزية، مع ملفات المصدر والصور والأيقونات والخطوط وبيانات المراكز المحلية وملخص الدفع وتصحيح أسعار المركبات. النسخة المصدرة مستقلة في عرضها عن استضافة Manus، ولم يُعدّل الموقع المنشور أثناء إعداد هذا الملف.

## النشر السريع دون بناء

فك ضغط الملف. داخل مجلد `taqdeer-netlify` يوجد مجلد `dist/public` يحتوي الموقع المبني الجاهز. افتح [Netlify Drop](https://app.netlify.com/drop)، ثم اسحب **مجلد `public` الموجود داخل `dist`** إلى منطقة الرفع. لا تسحب مجلد المشروع كله ولا `client/public`؛ هذان يحتويان المصدر أو أصولًا دون ملف تشغيل الواجهة المبني.

يشمل مجلد النشر `index.html` وملفات JavaScript/CSS المبنية وكافة الأصول المحلية، إضافة إلى `_redirects` حتى تعمل روابط مثل `/booking-appointment` و`/payment-summary` عند فتحها مباشرة أو تحديث الصفحة. صفحة ملخص الدفع تتطلب موعدًا مختارًا خلال جلسة التصفح نفسها؛ إعادة تحميلها لا تستعيد مدخلات حجز شخصية، لأنها غير محفوظة.

## النشر من مستودع Git

ارفع محتويات مجلد `taqdeer-netlify` إلى مستودعك، ثم اختر في Netlify استيراد المشروع منه. ملف `netlify.toml` يحدد إعداد البناء تلقائيًا:

- أمر البناء: `pnpm run build:static`
- مجلد النشر: `dist/public`
- Node.js: الإصدار22
- pnpm: الإصدار10.18.0

لا تحتاج هذه النسخة الثابتة إلى مفاتيح API أو قاعدة بيانات أو متغيرات سرية. يستخدم البناء ملفات المصدر تحت `client`، ويُنسخ كل محتوى `client/public` تلقائيًا إلى مجلد النشر. لا تجعل مجلد `client` هو Base directory؛ جذر المشروع هو موضع `package.json` و`netlify.toml`.

## التشغيل والتعديل محليًا

ثبّت Node.js22، ثم افتح الطرفية في مجلد المشروع:

```bash
corepack enable
corepack prepare pnpm@10.18.0 --activate
pnpm install --frozen-lockfile
pnpm dev:static
```

لإعادة إنشاء ملفات النشر بعد تعديل المصدر:

```bash
pnpm check
pnpm build:static
```

إذا عدّلت ملفات `client/public/original`، يمكن تشغيل `python3 reference/version_original_assets.py` قبل البناء لتحديث بصمات روابط السكربتات والبيانات. لا تعدّل `dist/public` بوصفه المصدر؛ سيُعاد إنشاؤه عند البناء.

## ما تحتويه الحزمة

يتضمن `client/src` مصدر واجهة React و`client/public` صفحات الأصل المنسوخة والأصول المحلية. يحتوي `client/public/build` خطوط Readex Pro وCSS الأصلي، و`media` و`assets` الصور والشعارات والأيقونات، و`vendor` ملفات الهاتف وأعلام الدول. توجد بيانات المدن والمراكز والمركبات والمواعيد تحت `client/public/original`.

أُرفقت أيضًا ملفات القالب البرمجية في `server` و`shared` و`drizzle` و`patches`، وملفات التبعيات والقفل والإعدادات، وبعض فحوص المشروع. هذه الملفات ليست خادمًا منشورًا على Netlify؛ الموقع الحالي يعمل كواجهة ثابتة. لم تُضمّن ملفات `.env` أو مفاتيح أو جلسات متصفح أو سجل Git أو `node_modules` أو سجلات استخدام، لأنها ليست ملفات لازمة للتسليم الآمن، ويمكن تثبيت التبعيات بأمر `pnpm install`.

أُزيلت من إعداد Vite في نسخة التصدير فقط إضافات تشخيص Manus، واستُبدلت إعدادات المنصة العامة بقيم فارغة، كي لا يحمل الملف إعدادات حساب أو يجمع سجلات المتصفح. يستخدم العرض خطوطه الأصلية المحلية، ولا يحتاج تنزيل صور الواجهة من الموقع الأصلي.

## حدود النسخة

هذه نسخة واجهات غير رسمية، وليست موقع تقدير الحكومي. تفاعلات اختيار المركبة والمركز والموعد والمراجعة وملخص الدفع محلية. لا يتم إنشاء حجز رسمي أو إرسال رمز جوال أو تنفيذ دفع أو جمع بيانات بطاقة. بيانات المراكز والمواعيد والأسعار من النسخ العامة التي جُمعت للمشروع، وليست اتصالًا حيًا بالخدمة الرسمية. إتاحة كل الأوقات في الواجهة هي التعديل المحلي المطلوب سابقًا، وليست حالة الحجوزات الرسمية. الخدمات الخارجية مثل روابط الخرائط تفتح مواقعها الطبيعية عند اختيارها.

لا توجد رسوم إضافية مخترعة. الملخص الحالي يعرض رسوم التقدير من صف المركز والفئة المحددين، مع ضريبة15%؛ لا يضيف رسوم التثمين تلقائيًا. يجب الحصول على التراخيص اللازمة لاستخدام الشعارات والمواد التي لا تملكها وعدم عرض هذه النسخة باعتبارها خدمة حكومية رسمية.

## مراجع إعداد Netlify

[دليل Vite الرسمي على Netlify](https://docs.netlify.com/build/frameworks/framework-setup-guides/vite/) يشرح إعداد مجلد النشر وإعادة كتابة مسارات تطبيق الصفحة الواحدة. يوضح [دليل الرفع اليدوي الرسمي](https://www.netlify.com/knowledge-base/deploy-your-lovable-app-to-netlify/) أن Netlify Drop يرفع ملفات الموقع المبنية ولا ينفذ أمر بناء تلقائيًا.
